## What is System Architecture?

In my own understanding of System Architecture, it is a blueprint on how each layers talk to each other, how everything will be built let's say 
how will the api talk to the frontend?

## Why is System Architecture important?

In modern days coding manually is not the best practice for developing these days. It is advisable for you to use Ai as it makes everything fast and makes the
workflow more efficient. In that sense you have to understand the architecture of your projects, you need to be able to understand how it's properly architectured
so that you can use Ai as your companion in terms of solving errors and bugs.
